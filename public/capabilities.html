什么是 MCP？

MCP（Model Context Protocol）是一种让 AI 平台连接外部工具的通用接口，例如连接网页检索、数据库或企业系统。不安装 MCP 也能使用 AIJAVAIS 的全部基础功能（模型协作、上传资料、生成 Word/Excel/PPT）。

需要在服务器上运行程序的 MCP Server 只能由服务器管理员在服务器配置文件中添加（防止网页上安装任意程序）。添加后可在这里测试连接。
