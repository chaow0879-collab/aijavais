# ADR-0002 最小消息总线

- 状态：已采纳（第二批，提交 `0fcdf8b`、`79cb152`）
- 决策：Task / Message / Event 三者分离。消息由 `lib/messages.js` 在内存中校验与流转；服务端控制 `messageId`、时间戳、发送者身份、状态。
- 范围：A→B→A 流水线的交接改为结构化消息，`handoff` 事件由消息**投递**驱动。同一供应商自审没有两个参与者，保留直连 handoff。
- 不做（留待调度器批次）：任务取消 / 重试 / 并行 / 预算；模型自主发起多轮提问；消息持久化。
- 风险：单条消息正文上限 20000 字符，超出会被截断并在 `metadata.truncated` 标记（下游应改用 `artifactRefs`）。
