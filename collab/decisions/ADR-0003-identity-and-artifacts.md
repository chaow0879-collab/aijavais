# ADR-0003 身份解耦与成果引用

- 状态：已实施（第三阶段 A，提交 `658f4c3`），待 OpenAI 复核
- 背景：第二批中同一供应商自审会绕过消息总线；长消息被截断后任务仍报告成功（P1-1 / P1-2）。
- 决策：
  1. connectionId / roleId / agentInstanceId 三层分开。消息总线只认实例 ID；注册失败任务直接失败，不切换执行机制。
  2. 超长正文存为任务内成果（`lib/artifacts.js`，内存，随任务一起在结束 1 小时后清理），消息携带引用；绝不把预览当全文。
  3. 事件 agentId 仍是 connectionId，大屏不需要修改。
- 后果：任务记录 `agents` 字段保存执行时的岗位与模型；成果正文不落盘，服务重启后不可取回（任务步骤输出仍在 tasks.json）。
