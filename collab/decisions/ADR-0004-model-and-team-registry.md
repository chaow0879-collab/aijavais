# ADR-0004 模型注册中心与团队注册中心

- 状态：已实施（第三阶段 B / C，提交 `e7df8d4`、`234cafe`），待 OpenAI 复核
- 决策：
  1. 模型连接注册信息（data/models.json）与凭证（data/credentials.json，0600）分离；任何接口不返回明文。
  2. 服务商目录与团队模板是版本化数据文件（catalog/*.v1.json）。新增服务商只改数据文件。模型名不预置，从服务商接口实时读取或由用户填写。价格与免费额度一律“未知 / 待验证”。
  3. 团队 = 岗位列表；每个岗位一个主模型 + 最多 5 个备用模型。换模型只改岗位分配。
  4. 费用策略默认 free_first + allowPaidApi=false：付费或费用未知的模型每次运行需显式批准（HTTP 402），不自动收费。直接指定模型运行视为本次已确认。
  5. 删除模型：运行中任务需 force；被团队引用需 replacement 或 detach；默认模型改为替代或清空；历史保留。
  6. 推荐只依据用户声明的能力、测试结果、状态、计费方式，所有未验证信息明确标注。
- 未做：monthlyPaidApiBudget 只存储不执行（没有经过验证的价格就无法计费）；多步骤工作流（steps）只记录，执行仍是主责 → 审核 → 主责修订；人工审批节点只记录。
