# REPO NEXUS · 产品规格与迭代地图

## 产品北极星

**通用团队内容资产协作 + 可信版本治理 + 便捷对外分发**。文件是独立的逻辑资产（Document），有多个不可变版本（Revision）；每个资产属于一个项目空间（Workspace）。成员操作留下可搜索审计信息。业务领域不应写死。

## 核心体验

1. 用户登录，从项目空间选择文件或创建文件。
2. 同空间同名上传默认“创建新版本”，旧版本自动归入历史仓库（对象不删除、旧下载链接不变）。用户可以主动选择“另存为独立文件”，避免误归并。
3. 能看到版本链、上传人、时间、大小、哈希、恢复/下载动作；恢复产生新版本而不是抹掉历史。
4. 分享文件时生成公开链接；仅知道链接的人可下载，匿名页面绝不暴露整个项目目录；提取密码、次数、有效期、撤销继续保留。
5. 团队成员至少有管理员、编辑者、浏览者三类；未来细化到工作区/文件 ACL、审批、外部协作者。

## 已具备的基础 API

| API | 权限 | 功能 |
| --- | --- | --- |
| `GET/POST /api/projects` | 成员 / 编辑者 | 项目列表、创建项目 |
| `GET /api/documents` | 成员 | 当前逻辑文件 |
| `GET /api/documents/:id/history` | 成员 | 版本列表 |
| `GET /api/documents/:id/compare?from=&to=` | 成员 | **仅元数据差异** |
| `POST /api/documents/:id/restore` | 编辑者 | 历史版本复制为新版本 |
| `POST /api/documents/:id/archive` | 编辑者 | 逻辑文件归档 |
| `POST /api/documents/:id/unarchive` | 编辑者 | 从归档中恢复 |
| `POST /api/upload?name=&projectId=&replace=auto` | 编辑者 | 新文件或同名覆盖自动归档 |
| `GET /api/versions/:id/download` | 成员 | 带权限历史版本下载 |
| `GET/POST /api/members` | 管理员 | 列出/创建成员 |
| `GET /api/audit` | 管理员 | 最近审计记录 |
| `POST /api/shares` | 编辑者 | 文件公开分享；允许锁定历史版本 |
| `DELETE /api/shares/:id` | 编辑者 | 撤销分享 |
| `GET /s/:token` | 公共 | 被授权的单文件下载/密码页面 |

## Codex 下一轮优先实现（从 P0 到 P2）

- **P0 生产数据可信度**：SQLite WAL + 原子事务、可靠旧版数据迁移、并发同名覆盖去重、跨进程重启恢复、备份/恢复/完整性检查；写入文件与元数据失败时回滚或修复孤儿对象。
- **P0 安全**：成员生命周期（禁用、密码重置、会话失效）、项目级 RBAC、严格限流、抗暴力破解、上传 MIME/文件签名校验、存储额度、XSS/CSRF/路径穿越/恶意压缩包验证、安全日志。避免将内部 API 暴露到未授权访客。
- **P0 分发业务完整性**：蓝奏云式独立下载页（文件名、大小、提取密码、下载按钮）、短链接管理、统计、批量生成、可复制 URL、分享绑定版本策略、链接失效明确提示、可选访客文件留言。
- **P1 内容比较/合并**：明确区分“新版本替换”和“真正合并内容”；文本 `.txt/.md/.csv/.json` 可先实现行级 Diff/冲突合并，Office（DOCX/XLSX/PPTX）可只读抽取变更摘要；禁止伪装成完整二进制自动合并。
- **P1 团队协作**：项目角色（owner/editor/reviewer/viewer）、文件评论/变更说明/审批发布、文件锁定/冲突提示、按标签/上传人/更新时间搜索、批量上传、回收站及回收期限。
- **P1 上传体验**：断点续传、分片上传、批量文件/拖拽、进度/重试、秒传去重、内容寻址、配额与清理。
- **P2 体验**：响应式科技风主控台、文件活动时间线、仪表盘、历史快照、工作区模板、自定义元数据、移动端下载/分享、可访问性、国际化。

## 不可违反的验收

- 未登录用户不能枚举项目、成员、文件列表、归档文件、审计和内部元数据。
- 同空间同名上传 V2 后，V1 仍存在且可下载；当前指针 V2；恢复 V1 后出现全新 V3；所有 SHA、上传人及时间正确。
- 不同文件误同名的风险有“独立文件上传”开关；不同项目间不得自动归并。
- 分发链接随机不可枚举；撤销/过期/次数用尽/错误提取密码均不能下载。
- 现有旧项目服务不受 repo 的启动、升级、回滚影响。
