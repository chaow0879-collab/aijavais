# AIJAVAIS 产品定位

AIJAVAIS 是**全行业通用型 AI 工作操作系统**：让用户围绕目标创建项目、选择可替换模型、自由设置 AI 岗位及边界、组织有限工作流、接入工具与 Skills、保存交接资料、审核返工并交付真实文件。

产品不以用户的历史职业、某一行业、某一家模型或大屏动画为中心。写作、软件、研究、教育、设计、运营和各专业行业都是可选项目类型。专业模板只提供指导，不代表平台具备对应执业资格、工程校核能力或已验证的专业工具。

## 当前交付与边界

当前有单管理员安全登录、模型/团队管理、23 类立项模板、可编辑岗位/标准/步骤、真实 HTTP 模型调度适配器、持久化岗位消息、有限流程、MCP stdio、声明式 Skills、审核/返工、预算账本与真实办公文件生成。

“真实执行”以实际网络/工具/文件证据为准，不以动画或模型口头声称为准。开发验证使用本地 Mock 模型和本地 MCP 协议 fixture；尚未调用收费真实厂商 API 或第三方生产 MCP。不能把测试连接成功当成专业能力验证。

本检查点仍为 **V2 WIP / 待 Claude 综合验收**：企业多用户、多租户、无界自主任务、模型自主工具选择、安全任意代码运行、通用附件读取、网页搜索及专业行业工具并未完整实现。当前是有限顺序工作流，不可宣传为全部目标已交付。

## 继续开发原则

优先完成通用项目闭环和实际交付验证，再增加领域插件。模型、岗位、团队、Skill、工具独立可替换；默认零未经批准费用；权限、预算、人工验收和持久化证据先于自主性扩展。详情以 FEATURE-STATUS 和 HANDOFF 为准。

## AIJAVAIS V2 普通用户操作说明

> 原 `docs/PRODUCT.md`（C1 文档收敛：原文照录，标题降一级）。

本说明只写**已经实现并可实际使用**的功能。还没做的会直接标明“尚未实现”。不需要懂代码。

### 1. 第一次使用：先看「能力中心」

登录后打开 **能力中心与就绪检查**（工作台顶部或管理中心顶部都有链接，地址 `/capabilities.html`）：

1. 勾选你的使用方式，例如“用 AI 团队完成文档、方案、分析等工作”“读取上传的 PDF/Word/Excel/PPT 资料”。
2. 页面会给出《AIJAVAIS 当前缺失配置清单》，分为 **必须配置 / 建议配置 / 按需配置**，每一项都写了怎么做。
3. “必须配置”清零后，就可以开始做项目了。可以点“复制清单文字”发给帮你维护服务器的人。

### 2. 除了模型 API Key，还需要什么？

| 项目 | 是否必须 | 说明 |
|---|---|---|
| 管理员密码 | 必须 | 首次部署时用服务器上的一次性设置码设置。 |
| 至少一个 AI 模型 | 必须 | 在「模型与团队 → 模型」添加。云端模型需要 API Key；也可以接入本机 Ollama 等本地模型（不需要 Key、不产生 API 费用）。 |
| 模型连接测试 | 必须 | 添加后点“测试”。远程模型测试会真实调用一次（最多 32 个输出 Token），可能收费，所以会先问你。 |
| 读取 PDF | 按需 | 服务器需要安装 poppler-utils（官方 Docker 镜像已内置）。Word/Excel/PPT/文本不需要额外安装。 |
| Office 转 PDF、页面渲染检查 | 按需 | 服务器需要安装 LibreOffice。 |
| MCP 外部工具 | 按需 | 基础功能**不需要**。 |
| HTTPS | 公网访问时必须 | 本机使用不需要。 |
| 备份 | 建议 | 平台无法知道你是否备份过，请定期备份（见第 8 节）。 |

注意：ChatGPT、Claude 等网页版或 App 会员**不包含** API 额度。API Key 需要在服务商官网的 API 管理页面另行创建。

### 3. 哪些功能免费，哪些需要额外服务？

**平台自带、免费（不额外收费）**：上传并读取资料文件、读取 PDF 文字、生成 Word/Excel/PPT、导出 CSV/Markdown/JSON/代码压缩包、数据计算与分析、柱状/折线/饼图、Office 转 PDF 与渲染检查（后两项需服务器装 LibreOffice）、文本与 JSON 检查。

**会产生费用的**：调用云端 AI 模型（按服务商价格计费）。平台默认不调用收费或“免费资格未验证”的模型；每次运行都要你单独批准，并填写单价、Token 上限和金额上限。平台的费用是**估算**，以服务商账单为准。

**需要第三方服务、尚未接入**：联网检索、图片生成。可以通过远程 MCP 接入（见第 5 节），或把网页另存为 PDF 后作为资料上传。

**默认关闭、需服务器管理员开启**：受控代码执行（仅 JavaScript，无网络、只能访问临时目录；开启后每次运行仍需勾选授权）。

**尚未实现**：流程图/结构示意图、识别图片内容（OCR/看图）、把图表直接嵌入 Word/PPT。能力中心里这些会显示为“尚未实现”，平台不会假装完成。

### 4. 做一个项目（不需要写代码）

1. **智能立项**：用一句话描述任务（任何行业都可以），选择项目类型，回答几个量化问题，调整岗位和步骤。
2. 最后一步会显示 **平台工具实时检查**：每项需要的能力是“可用 / 需要配置 / 平台尚未实现”，以及替代方案。缺少的工具不会被当作已完成。
3. 点“保存草案并进入工作台”。
4. 在工作台：
   - **项目资料**：上传需求、数据、合同等文件；可预览平台实际读到的文字。可以选择“全部资料 / 只用勾选的资料 / 不使用资料”。图片目前只保存、不识别。
   - **AI 岗位**：为每个岗位选择模型；岗位、职责、标准都可以增删改。不同项目可以用完全不同的团队。
   - **执行流程**：调整步骤顺序和负责人；后一个岗位会收到前一个岗位的完整成果。
   - **执行权限与费用上限**：勾选本次允许使用的工具，填写 Token 和金额上限；使用远程收费模型时勾选“批准本次付费调用”并填写单价。
5. 点“检查执行条件”，通过后点“开始执行任务”。
6. 在「执行与交付」查看每一步的真实输入输出、交接消息、工具结果、Token 与估算费用；完成后**人工审核**：通过，或写明意见后返工（最多 5 轮，每轮重新批准费用）。
7. 选择格式生成并下载真实文件（Word、Excel、PPT、CSV、Markdown、JSON、代码压缩包）。

### 5. MCP 是什么？怎么启用？

MCP（Model Context Protocol）是让 AI 平台连接外部工具的通用接口，比如网页读取、数据库、企业系统。

- **不装 MCP 也能用全部基础功能。**
- **远程 MCP**（服务商给你一个 https 地址）：能力中心 → MCP 管理 → “添加远程 MCP”，填名称、地址，如有访问令牌就填上（保存后不再显示）。暂不支持需要 OAuth 网页登录授权的服务。
- **本机 MCP 程序**：为了安全，网页上不能安装程序。请服务器管理员按“MCP 目录”里的说明安装固定版本，并写入服务器配置文件；之后你可以在页面上测试、启用或停用。

### 6. 如何确认工具真的可用？

1. 能力中心 → 全部能力：状态为“可用”才是真实可用；“需要配置”说明还差安装或设置；“尚未实现”就是目前没有。
2. MCP 管理：点“测试连接”会真的连接一次；“工具调用测试”会真的调用一次并原样显示结果；所有结果写入“运行日志”。
3. 项目执行后，在「执行与交付」的步骤记录里能看到每个工具的实际结果文件。**模型说“我已经调用了工具”不算数，以工具结果记录为准。**

### 7. 常见问题

| 现象 | 处理 |
|---|---|
| 模型测试失败，提示 Key 无效 | 重新从服务商 API 页面复制 Key；确认不是网页会员账号。 |
| 模型测试提示网络/DNS 失败 | 服务器无法访问模型服务商，请维护人员检查网络或代理。 |
| 提示需要批准付费调用（402） | 正常的保护措施：在执行权限里勾选批准，并填写单价和金额上限。 |
| 上传 PDF 后显示“服务器缺少解析程序” | 服务器需安装 poppler-utils；或把 PDF 另存为 Word 后上传。 |
| PDF 显示“没有可读取的文字” | 多半是扫描件，目前没有 OCR。 |
| 显示“工具未授权” | 在执行权限中勾选该工具后再运行。 |
| 检查执行条件提示缺少工具 | 按能力中心的说明配置，或在项目中移除该工具要求，并改用替代方案。 |
| 取消任务后仍有费用 | 已经发出的模型请求可能已经计费；平台按保守估算记账，以服务商账单为准。 |

### 8. 数据与备份

所有项目、资料文件、成果和账本保存在服务器的数据目录。维护人员应定期执行 `npm run db:backup -- /私有目录/备份文件.sqlite`，并完整备份整个数据目录（其中含模型 Key，不能公开）。不要把数据目录、Key 或备份发到聊天群或代码仓库。
