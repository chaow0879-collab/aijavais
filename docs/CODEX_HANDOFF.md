Codex 担任总协调者，自主决定实际角色数量、可用子代理和任务分工；覆盖产品/交互、科技风 UI、文件版本和归档、成员授权、安全审计、QA、部署等必要能力。真实支持子代理才创建，其他情况下单 Agent 分角色执行，记录 `SUBAGENT_CAPABILITY_UNAVAILABLE`。维护 `docs/AGENT_PLAN.md` 和最终验收证据；普通问题内部自行修复，不反复找用户。

## 开发重点

- 通用团队项目文件库、成员角色和访问权限。
- 同项目同名上传新版本，旧版自动归档、不可变版本链、版本恢复生成新的最新版本；版本上传人、SHA、时间、说明可追溯。
- 科技风响应式界面，提供项目、版本时间轴、历史档案、分发中心、审计视图。
- 蓝奏云式单文件随机下载链接、密码、有效期、次数限制、随时撤销。匿名无目录索引。
- 实现真实文本差异/安全合并，Office/ZIP 二进制文件不虚报自动内容合并。
- 现版 v2 的 JSON 元数据需升级为可事务化持久库（SQLite WAL 适宜），配合限额、权限、备份与恢复，保留旧数据迁移。
