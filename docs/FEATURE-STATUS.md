# V2 功能实况（以代码与测试为准）

更新：2026-11-05，分支 `feat/claude-v2-followup`。验证口径：**真实** = 真实文件/真实 SQLite/真实子进程或系统程序；**Mock** = 本地模型 HTTP fixture；**fixture** = 本地 MCP 协议 fixture；**未实测** = 未对真实厂商或第三方服务验证。

| 需求 | 已实现 | 验证方式 | 尚未完成或未真实验证 |
|---|---|---|---|
| 安全登录/独立部署 | 单管理员 scrypt/会话/只读大屏/限流；HTTPS 配置；Docker 非 root；并行部署手册 | 单元+HTTP；CI 构建镜像 | 企业账户/SSO/多租户；负责人服务器上的并行部署尚未执行 |
| 模型注册测试替换推荐 | 两种流式协议、凭据分离、试连、替换、声明能力推荐；Anthropic 模型列表发现已修复 | Mock + Anthropic 协议 fixture | 真实收费厂商未测；能力标签为用户声明；免费资格未实证 |
| 立项智能指导 | 六步向导、23 类模板、自定义岗位/标准；**服务端实时工具检查**（可用/需配置/未实现、替代方案） | 单元+HTTP+浏览器 | 规则引擎，不是 LLM 主动访谈；动态生成全新团队结构仍依赖模板+手工调整 |
| AI 岗位与职责 | 项目/团队岗位可增删，职责/边界/标准进入 prompt；11 个通用团队模板 | 单元+浏览器 | 团队备用模型未接入 V2 自动切换 |
| 多 AI 协作与交接 | 每岗真实适配器调用、持久消息、前一步完整输出交接 | Mock | 后续岗位只收到上一步输出（不含更早步骤全文）；真实厂商组合未验证 |
| 文件上传/读取/交接 | 上传 PDF/DOCX/XLSX/PPTX/文本/CSV/JSON/代码；提取文字、分段读取、下载原件、删除；运行快照记录 SHA-256 与实际提供字数 | 外部工具生成的真实文件 + 恶意输入用例 + 浏览器 | 图片不识别（无 OCR/看图）；扫描 PDF 无文字；不支持原地编辑已上传 Office 文件 |
| 办公文件与代码交付 | DOCX/XLSX/PPTX/CSV/MD/JSON/代码 ZIP；Office→PDF 转换；页面渲染 PNG 与空白页检查 | 独立解析器 + LibreOffice + poppler | 渲染需 LibreOffice；图表不能直接嵌入 Word/PPT；未人工逐页审稿 |
| 数据分析与图表 | 确定性描述统计/分组汇总/排序/筛选，结果可存 XLSX/CSV；SVG 柱状/折线/饼图 | 单元（与 Python 交叉核对）+HTTP | 无公式计算；流程图/结构图未实现 |
| 能力中心与就绪检查 | 内置/MCP/Skill/外部服务/未实现分类，状态实时计算；按场景生成《缺失配置清单》 | 单元+HTTP+浏览器 | 无法确认用户是否已备份；网络检查不做真实外呼 |
| MCP | stdio + **远程 Streamable HTTP**（静态令牌）；审核目录、启停、连接测试、调用测试、诊断、运行日志、移除远程连接 | fixture（stdio 与 HTTP） | 无 OAuth；第三方生产 MCP 未验收；本机 MCP 程序以服务账户权限运行，不是沙箱 |
| Skills | 版本化 prompt/tool/check，前后执行，持久化 | 单元 | 不是任意外部技能包执行器 |
| 审核返工质检 | 文本/JSON 检查、人工批准、最多 5 轮返工、取消 | Mock | 领域质量需专业工具/人工 |
| Token 与费用 | 每次运行/返工明确批准、USD 价表、Token/金额预留、部分/失败/未知用量账本 | Mock | 非厂商账单对账；32-token 远程试连未计入项目账本 |
| 真实过程可视化 | 大屏真实事件/SSE，工作台步骤/消息/工具/账本 | Mock | 真实厂商长任务未压测 |
| 受控代码执行 | JavaScript：网络命名空间（无网络）+ Node 权限模型（文件仅限临时目录、禁子进程/eval）+ 超时/内存/输出上限；**默认关闭**，管理员 `AIJ_ENABLE_CODE_EXECUTION=1` 且每次运行授权 | 真实隔离测试（读取外部文件、联网、子进程均被拒） | 不是强安全沙箱；容器默认安全策略下多半无法创建命名空间→工具拒绝运行；不支持 Python/shell |
| 联网检索/图片生成 | 可通过远程 MCP 接入 | — | 平台内置**尚未实现** |
| 测试与部署 | `npm test` 185 项；两个浏览器测试；CI 三个任务（含 poppler、LibreOffice、Python 解析器） | 远程 GitHub Actions 实际运行 | 公网部署/灾备恢复演练未做 |

WIP 指以上仍需发展的能力，不表示已有实现可以丢弃。测试口径见 [TESTING.md](TESTING.md)，交接见 `collab/HANDOFF.md`。
